# Twin Rim-Driven Propulsor UAV Control System

Modeling and control analysis of a small UAV architecture using
two independently vectored rim-driven propulsors for propulsion
and vehicle control.

## Project Overview

This project investigates whether differential thrust and
multi-axis thrust vectoring can provide sufficient control
authority for a compact UAV while reducing reliance on
conventional aerodynamic control surfaces.

The current work focuses on nonlinear aircraft dynamics,
actuator modeling, control allocation, and comparison of
alternative propulsion/control architectures.

## Current Objectives

- Develop a nonlinear 6-DOF aircraft model
- Model forces and moments generated by vectored propulsors
- Develop actuator-to-wrench mappings
- Investigate constrained control allocation
- Quantify actuator saturation and available control authority
- Compare twin-propulsor and tail-assisted configurations
- Develop toward SIL/HIL testing
